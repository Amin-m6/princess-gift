# Princess.exe — Snake Mini App

یک بازی تک‌نفره‌ی Snake با تم ذغالی و طلایی، شوخی‌های دوستانه، خوراکی‌های ویژه و پایان‌های متنوع.

## اجرا روی کامپیوتر

1. فایل ZIP را از حالت فشرده خارج کن.
2. `index.html` را در مرورگر باز کن. برای اجرای محلی ساده همین کافی است.
3. اگر مرورگر محدودیتی ایجاد کرد، پوشه را با یک سرور محلی اجرا کن؛ مثلاً در ترمینال داخل پوشه:
   ```bash
   python -m http.server 8000
   ```
   سپس به `http://localhost:8000` برو.

## کنترل‌ها

- کلیدهای جهت‌دار یا WASD
- دکمه‌های روی صفحه یا کشیدن انگشت روی زمین بازی در موبایل
- Space یا دکمه مکث برای توقف موقت

## امکانات فعلی

- Snake تک‌نفره
- امتیاز و بهترین رکورد با `localStorage`
- موز، کیک، چای، دوغ و جایزه طلایی
- اثر موقت دوغ و چای
- رویدادهای تصادفی با فاصله‌ی زمانی کنترل‌شده: آزمون رانندگی، حالت پرنسس و چای تمرکز
- صفحه پایان رنگارنگ با انیمیشن شکستن قلب؛ پیام‌های پایان مختلف: شکست، رکوردشکنی، رانندگی، شوخی و پیام گرم
- موزیک ۸ بیتی و جلوه‌های صوتی ساخته‌شده با Web Audio (بدون فایل صوتی؛ با اولین لمس شروع می‌شود و با دکمه ♫ خاموش/روشن می‌شود)
- پیام‌های متنوع وسط بازی (شوخی با پرنسس، رژیم، گواهینامه، دیوار و ...)
- طراحی واکنش‌گرا برای موبایل
- بدون پایگاه داده و بدون نیاز به بک‌اند برای خود بازی

## نکته درباره رکورد

رکورد فقط در همان مرورگر/فضای ذخیره‌سازی دستگاه نگهداری می‌شود. پاک‌شدن داده‌های سایت یا بازشدن Mini App در محیط ذخیره‌سازی متفاوت ممکن است رکورد را از بین ببرد.

## اتصال به Telegram Mini App

این پوشه فعلاً نسخه‌ی فرانت‌اند بازی است. برای انتشار داخل تلگرام:
1. فایل‌ها را روی یک میزبان استاتیک با HTTPS قرار بده.
2. در BotFather یک ربات بساز و از بخش تنظیمات Mini App، آدرس HTTPS بازی را تنظیم کن.
3. برای دکمه‌ی منوی ربات یا دکمه‌ی وب‌اپ از URL منتشرشده استفاده کن.

برای این نسخه‌ی تک‌نفره، توکن ربات لازم نیست داخل JavaScript قرار بگیرد؛ آن را در کد سمت مرورگر قرار نده. اگر بعداً احراز هویت واقعی تلگرام اضافه شد، اعتبارسنجی باید سمت سرور انجام شود.
